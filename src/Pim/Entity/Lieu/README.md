# Domaine Lieu

Ce dossier regroupe uniquement les entités nécessaires à un lieu : l’entité
principale, ses blocs administratif et tarifaire, ses salles, ses fermetures,
ses accès et ses références vers le DAM.

Les informations communes comme l’identité de la fiche et la localisation
restent dans le dossier parent afin d’être réutilisées par les futures familles
du PIM.
